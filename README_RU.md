# Inpaint Universal 4.1 для ComfyUI

[**Руководство пользователя на русском**](GUIDE_RU.md) · [English user guide](GUIDE_EN.md)

[Installation in English](README.md) · [Модели, пути и ссылки](MODELS.md)

Редактор для прозрачных PNG. Можно перерисовывать выделенный фрагмент через SDXL или вручную работать с прозрачностью, контуром, светотенью и фактурой. В комплекте есть умное выделение SAM, направляющая для складок и швов, образцы IP-Adapter и генерация предметов с выходом за силуэт.

## Перенос на другой компьютер

1. Скопируй **всю папку Inpaint**, включая `models`. Установи и один раз запусти ComfyUI для своей видеокарты, затем закрой его. Проверенная связка — **ComfyUI 0.12.2 и frontend 1.37.11**. [Установка ComfyUI Portable](https://docs.comfy.org/installation/comfyui_portable_windows)
2. Открой PowerShell **в скопированной папке Inpaint**, укажи свой путь к ComfyUI Portable и выполни команды ниже. На диске назначения понадобится **9,42 ГБ** под вспомогательные модели. При совпадении файлов установщик их пропустит. Если файлы отличаются, он покажет пути до начала копирования.
3. При установке **из GitHub** веса скачиваются отдельно. В таблице [MODELS.md](MODELS.md) указано, что скачать, как назвать и куда положить. В локальной копии уже есть восемь вспомогательных файлов. Для генерации выбери свой обычный SDXL 1.0 чекпойнт под стиль изображения. Если он уже установлен в ComfyUI, скачивать его повторно не требуется. Новый чекпойнт положи в `ComfyUI/models/checkpoints/`.
4. Запусти ComfyUI, обнови вкладку и открой **Рабочие процессы → Inpaint_Universal_v4_1**. Также можно перетащить `user/default/workflows/Inpaint_Universal_v4_1.json` из комплекта прямо на холст.

```powershell
$portable = 'D:\ComfyUI_windows_portable'
& "$portable\python_embeded\python.exe" -s .\install.py "$portable\ComfyUI"
& "$portable\python_embeded\python.exe" -s -m pip install -r .\requirements.txt
```

Для обычной установки или Linux используй Python из окружения ComfyUI вместо `python_embeded\python.exe`. Скрипту копирования нужен Python 3.11 или новее. Укажи папку, где находится `main.py`. PyTorch и torchvision ставятся вместе с ComfyUI под конкретную видеокарту.

### Если копируешь руками

| Что взять из Inpaint | Куда положить в ComfyUI |
|---|---|
| Четыре папки из `custom_nodes/` | В `custom_nodes/`, каждую на первом уровне |
| `input/Inpaint_V41_fabric.png` | В `input/` |
| `user/default/workflows/Inpaint_Universal_v4_1.json` | В `user/default/workflows/` или открыть файл с диска |
| Содержимое `models/` | В `models/` с сохранением подпапок |

После ручного копирования установи `requirements.txt` командой выше. У рабочей и переносимой V4.1 одинаковые идентификаторы нод. Чтобы сохранить обе версии, ставь переносимую сборку в отдельный экземпляр ComfyUI.

## Как проверить установку

1. В графе уже открыт синий лоскут. На нём отмечена красной маской торчащая нить. В раскрытой ноде **Модель SDXL** выбери свой чекпойнт из списка и сохрани workflow, чтобы запомнить выбор. Нажми **Запустить**, чтобы проверить мягкую ретушь.
2. Для своей работы нажми **Загрузить PNG с компьютера → Выделить область кистью**. Выбери слева **Маска правки**, закрась нужный участок, нажми **Сохранить правки**. Выбери режим, заполни желаемый результат и запусти генерацию.
3. **Сохранить результат** записывает готовый прозрачный PNG в `output/Inpaint_V4/`. **Продолжить редактирование** сразу открывает выбранный результат в окне кисти. Промежуточные PNG хранятся во временной папке.
4. Для ручной правки очисти красную маску, поправь прозрачность, контур или светотень и нажми **Сохранить правки**. Результат появится сразу. **Очистить все маски** сохраняет уже исправленный контур.

## Переключение языка и Grok

В первой ноде есть **Inpaint · Язык / Language**. Выбери **Русский** или **English**, сохрани открытые правки и workflow, затем нажми **F5**. Выбор запоминается в браузере. При первом открытии используется язык браузера. Язык оболочки ComfyUI меняется в её собственных настройках.

### Как подключить свой ключ Grok

Эта настройка нужна для кнопки **Подготовить промпт**. С ручными промптами Inpaint работает локально.

1. В своём аккаунте открой раздел **API Keys** и создай ключ. Подготовь также ID текстовой модели Grok, доступной твоему аккаунту. [Создать ключ](https://console.x.ai/team/default/api-keys) · [Модели xAI](https://docs.x.ai/developers/models)
2. **После установки**, на компьютере, где запущен сервер, открой в Блокноте **`ComfyUI/inpaint-grok.local.json`** рядом с `main.py`. Установщик создаёт пустой файл. При ручной установке создай его сам с этим точным именем и расширением `.json`.
3. Вставь ключ между кавычками поля **`api_key`**, а ID модели — в **`model`**. Сохрани файл. При следующем нажатии **Подготовить промпт** помощник прочитает новые значения.

```json
{
  "api_key": "",
  "model": ""
}
```

Переносимая версия берёт ключ только из этого файла. Оставь заполненный файл на своём компьютере. В xAI отправляются текст описания и выбранный режим при подготовке промпта. Кэш хранится в `ComfyUI/user/inpaint/prompt-cache/`.

Если у тебя **уже установлена предыдущая переносимая версия**, закрой её сервер, скопируй обновлённые `prompt_assistant.py` и `messages.py` из `custom_nodes/png_inpaint_v4/` комплекта в одноимённую папку своей установки и снова запусти ComfyUI. Файл настроек можно создать по примеру выше.

## Если что-то не открывается

- **Красные ноды.** Проверь четыре папки в `custom_nodes` и ошибки импорта в консоли запуска. Установи зависимости через тот же Python и перезапусти сервер.
- **Не найден чекпойнт или патч.** Выбери установленный обычный SDXL-чекпойнт. Проверь оба файла Fooocus в `models/inpaint`. Для отдельных инструментов сверь имена с [таблицей моделей](MODELS.md).
- **Мало видеопамяти.** Начни с одного варианта и рабочего фрагмента 768 px. Подключай ControlNet и IP-Adapter по задаче.
- **После обновления старое окно кисти.** Сохрани правки и workflow, перезапусти ComfyUI и обнови страницу через Ctrl+F5.

Для GitHub в комплекте есть `.gitignore` с исключением весов, чистый стартовый граф и [сведения о стороннем коде](THIRD_PARTY.md).
